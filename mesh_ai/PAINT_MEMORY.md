# Värvi- ja närvimälu Paint vaade

Ava paneeli käivitamise järel <http://127.0.0.1:8765/paint.html>. Joonistused salvestuvad ainult selle brauseri `localStorage`-isse; ekspordi JSON varukoopiaks või teise arvutisse viimiseks. „Salvesta kirjeldus AI mällu” kirjutab sõlmede ja seoste tekstilise kokkuvõtte olemasolevasse lokaalsete märkmete API-sse, mitte pildiandmeid.

Kihid ja jooned on visuaalne mälu. Sõlm tähistab inimese kirjeldatud mõtet ning ühendus inimese loodud seost; need pole päris bioloogilised neuronid ega anna AI-le iseenesest tundeid või tähendust. Vali sõlm ja küsi selle kohta Alpha+Betalt. Kohalik Ollama saadetakse päringusse ainult siis, kui kasutaja märgib selle valiku.
